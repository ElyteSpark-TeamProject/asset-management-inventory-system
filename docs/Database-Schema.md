# Database Schema (MongoDB / Mongoose)

## 1. User / Employee (`backend/models/User.ts`)
- `name` (String, required)
- `email` (String, required, unique)
- `password` (String, required)
- `role` (Enum: ["Admin", "Employee"])
- `department` (String)

## 2. Asset (`backend/models/Asset.ts`)
- `name` (String, required)
- `category` (String, required)
- `serialNumber` (String, unique)
- `status` (Enum: ["Available", "Assigned", "Maintenance", "Retired"])
- `purchaseDate` (Date)

## 3. Assignment (`backend/models/Assignment.ts`)
- `asset` (ObjectId -> Asset)
- `assignedTo` (ObjectId -> User)
- `assignedBy` (ObjectId -> User/Admin)
- `assignedDate` (Date)
- `returnDate` (Date, null if active)
- `conditionOut` (String)
- `conditionIn` (String)
