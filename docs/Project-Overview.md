# Project Overview

**Project Title:** IBM Client Project – Asset Management & Inventory Tracking System
**Client:** Corporate Organization (via IBM)
**Timeline:** 30 Days (Internal Safeguard: 15 Days)

## Objectives
Develop an internal full-stack web application to manage company assets (laptops, monitors, software licenses, etc.). The system allows administrators to assign assets, track inventory, and generate reports.

## Key Features
- User Authentication & Role-Based Access (Admin/Employee)
- Employee Management
- Asset Management (CRUD operations)
- Asset Assignment & Return Module
- Inventory Tracking (Search & Filter)
- Dashboard with Statistics
- Report Generation
